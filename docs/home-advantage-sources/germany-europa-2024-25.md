# German guaranteed Europa profiles, 2024/25

The `leverkusen-hoffenheim-2024-25.json` batch contains all 34 Bundesliga home matches for Bayer Leverkusen and Hoffenheim, 17 per club.

- Results source: OpenFootball Deutschland, complete 2024/25 Bundesliga season.
- Strength source: the project's generated 2026 UEFA club-coefficient snapshot.
- German opponents without a higher individual value use the `18.580` association floor.
- Historical pot fields remain neutral at `1`.
- Under the current coefficient snapshot, every Hoffenheim league opponent falls into the stronger-opponent bucket.

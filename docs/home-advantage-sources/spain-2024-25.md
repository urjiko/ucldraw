# Spain 2024/25 home-match source

The `real-betis-villarreal-2024-25.json` batch contains all 57 La Liga home matches for Real Madrid, Real Betis, and Villarreal, 19 per club.

- Results source: OpenFootball Spain, 2024/25 Primera División.
- Strength source: the project's generated 2026 UEFA club-coefficient snapshot.
- Spanish opponents without a higher individual club value use the `19.409` association floor.
- Historical pot fields remain neutral at `1`.
- The runtime slug `villareal` is retained for compatibility; source and display names use Villarreal.

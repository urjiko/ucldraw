# Ukraine and Czechia 2024/25 home-match sources

The `shakhtar-slavia-2024-25.json` batch completes the guaranteed Champions League profile scope.

- Shakhtar Donetsk: all 15 Ukrainian Premier League home matches.
- Slavia Prague: all 18 Czech First League home matches, including three championship-round home fixtures.
- Results source: OpenFootball Europe 2024/25 national-league datasets.
- Strength source: the project's generated 2026 UEFA club-coefficient snapshot.
- Unmatched Ukrainian opponents use the `5.182` association floor.
- Unmatched Czech opponents use the `9.705` association floor.
- Historical pot fields remain neutral at `1`.
